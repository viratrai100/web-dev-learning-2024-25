## React + GSAP (Vite)

Vite + React project demonstrating GSAP animations and ScrollTrigger.

### 🚀 How to Run
```bash
cd 10-React+GSAP/gsap
npm install
npm run dev
# build & preview
npm run build
npm run preview
```

## 🎯 Summary & Purpose
Show basic GSAP timelines, stagger animations, and scroll-triggered effects.

### 📘 What I Learned
- Initializing GSAP in React
- Creating timelines and chained animations
- Using ScrollTrigger for on-scroll effects

### 🧰 Technology Used
- React
- Vite
- GSAP, GSAP ScrollTrigger

### 🔧 How to Run From Scratch
```bash
npm create vite@latest gsap -- --template react
cd gsap
npm install gsap
npm run dev
```
