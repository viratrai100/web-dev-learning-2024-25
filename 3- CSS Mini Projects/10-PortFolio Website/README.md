# 🎯 Portfolio Website - Virat Rai

## 🚀 Technologies Used

- **HTML5**
- **CSS3**
- **Animate.css**
- **Responsive Web Design**
- **Custom Media Queries**

## 📌 Sections Included

- **Hero Section:** Personal introduction with animated effects.
- **Projects Section:** Displays 9 featured frontend projects.
- **Contact Section:** Social links with logos and contact methods.
- **Footer:** Dynamic copyright.
