# 🍽️ Restaurant Project

A visually engaging restaurant landing page with modern UI and a structured layout, built entirely using **HTML** and **CSS**. This project focuses on layout design, responsiveness, grid systems, and component-based structure.

---

## 🚀 Live Demo

- **Vercel:** [Click here](https://css-mini5-resturant-website-by-viratrai.vercel.app/)
- **Netlify:** [Click here](https://cssmini5-resturantwebsite-by-viratrai.netlify.app/)

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox & CSS Grid
- Media Queries for Responsiveness
- Google Fonts

---

## 📚 What I Learned

- Creating flexible and responsive layouts using **Flexbox** and **Grid**.
- Building a navigation bar with sticky behavior.
- Designing and aligning hero and feature sections effectively.
- Structuring a multi-area CSS grid layout for the menu showcase.
- Improving hover interactions and transitions with subtle animations.
- Responsive design implementation for mobile screens using media queries.
- Enhancing UI with consistent branding and reusable components.
