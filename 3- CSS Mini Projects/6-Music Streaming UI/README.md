# 🎵 myTunes Music Project

myTunes is a sleek, responsive landing page designed to showcase an all-in-one entertainment platform for music, movies, and TV shows. It imitates a real-world product experience and emphasizes a polished layout, structured content, and responsive design elements.

---

## 🔗 Live Demo

- **Vercel:** [Demo Link](https://css-mini6-music-website-by-viratrai.vercel.app/)
- **Netlify:** [Demo Link](https://css-mini6-music-website-by-viratrai.netlify.app/)

---

## 🛠️ Technologies Used

- **HTML5** – For semantic structure
- **CSS3** – For modern styling and responsive layout
- **Google Fonts** – Roboto font for clean typography
- **CSS Variables** – For color theming and design consistency

---

## 📚 What I Learned

- How to build a fully responsive multi-section website
- Usage of CSS Grid and Flexbox for layout management
- Implementing smooth scrolling with `scroll-behavior: smooth`
- Sticky navigation bar with `position: sticky` and `z-index`
- Importance of semantic tags and accessibility through proper sectioning
- Enhanced visual design with background images, box shadows, and color layering
