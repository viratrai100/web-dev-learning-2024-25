# 🎬 YouTube Homepage Clone

This project is a responsive front-end clone of the YouTube homepage. It replicates the layout, structure, and visual style of YouTube's main interface using HTML and CSS. The design includes a sidebar, top navigation, search bar, avatar section, tags, and a grid of video cards, all fully styled to resemble the real platform.
