# 📘 JavaScript Documentation

A clean, responsive, single-page technical documentation site that introduces core JavaScript concepts. Built using only **HTML** and **CSS**, this project is inspired by MDN-style documentation and provides learners a structured overview of JavaScript fundamentals.

---

- **Vercel:**  [Live Link](https://css-mini8-js-docs-page-by-viratrai.vercel.app/)
- **Netlify:** [Live Link](https://css-mini8-js-docs-page-by-viratrai.netlify.app/)

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Design with Media Queries
- Google Fonts (Roboto)

---

## 📚 What I Learned

- Built a fixed vertical navigation menu using `position: sticky` for seamless documentation browsing.
- Styled content sections with spacing, typography, and consistent theming.
- Used smooth scroll behavior for anchor navigation.
- Managed code blocks with proper padding, line-height, and `white-space: pre-line` for legibility.
- Implemented a mobile-first responsive design where layout adapts gracefully on smaller screens by stacking the sidebar and main content vertically.
- Learned how to create accessible and readable technical documentation using semantic HTML elements like `<section>`, `<article>`, and `<code>`.
