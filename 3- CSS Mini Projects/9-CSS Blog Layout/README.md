# 📰 Blog Project - Great Zone by Virat Rai

This is a stylish and responsive blog-style project titled **Great Zone**, consisting of two main HTML pages — `home.html` and `post.html`. It displays a hero section, featured articles, and a detailed blog post view. The layout uses Flexbox and Grid, and is styled entirely with custom CSS.

## 🔗 Live Demo

- **Vercel:**  [Live Vercel Link](https://css-mini9-blog-layout-by-viratrai.vercel.app/)
- **Netlify:** [Live Netlify Link](https://css-mini9-blog-layout-by-viratrai.netlify.app/)

## 🛠️ Technologies Used

- **HTML5** – For structure and layout
- **CSS3** – For design and responsiveness
- **Flexbox** – For horizontal and vertical alignment
- **Grid Layout** – For organizing card layouts
- **Google Fonts** – Typography with `Inter` font
- **Responsive Design** – Mobile-first approach with fluid layout
- **SVG Icons** – Used social icons for modern UI
- **Sticky Header** – Maintains navigation visibility

## 📄 Project Pages

### `home.html`
- Hero section with image and call to action
- Highlighted horizontal card
- Grid of vertical blog cards
- Final large horizontal feature card
- Sticky header with logo and social links
- Footer with repeated social links and copyright

### `post.html`
- Banner image and title
- Author section
- Article content with multiple paragraphs and subheadings
- Responsive layout for content readability

## 💡 What I Learned

- How to build a multi-page layout project with shared CSS
- Creating reusable card components with both horizontal and vertical orientations
- Using Flexbox and Grid together for complex responsive designs
- Working with sticky headers and consistent footers
- Managing internal navigation across pages
- Styling with utility classes and modular patterns
