# 🚀 JavaScript Theory - Pehla Program (Hello World)

This is my **very first JavaScript program**, created as part of my learning journey. It simply logs a message `"Pehla Program"` to the browser console to ensure everything is working correctly with basic setup.

## 📂 About This Code

This project contains a basic HTML file linked with a JavaScript file. The script uses `console.log()` to print a simple message — the traditional "Hello World"-style starting point.

```javascript
console.log("Pehla Program");
```

It helps confirm:
- JavaScript is correctly linked to HTML
- Developer tools console is being used
- Basic syntax is understood

- JavaScript (Vanilla)
