# ⚙️ JavaScript Theory - Operators & Conditional Statements

This code covers a detailed breakdown of **operators** and **conditional (control flow) statements** in JavaScript. It’s an essential part of learning how logic and decision-making works in programming.

## 📂 About This Code

This theory file includes multiple practical examples and explanations for:

### ✅ Types of Operators:
- **Arithmetic Operators** (`+`, `-`, `*`, `/`, `%`, `**`)
- **Increment/Decrement Operators** (`++`, `--`, pre/post)
- **Assignment Operators** (`=`, `+=`, `-=`, `*=`, `/=`)
- **Comparison Operators** (`>`, `<`, `>=`, `<=`, `==`, `===`)
- **Logical Operators** (`&&`, `||`, `!`)
- **Bitwise Operators** (`&`, `|`, `~`)
- **Ternary Operator** for inline condition handling

### ✅ Conditional Statements:
- `if`
- `if-else`
- `if-else-if`
- `switch` and `switch + break`
- Concept of **short-circuiting** in logical expressions
- Working with **non-boolean** values in logical operations

### Sample Concepts Covered:

```javascript
let a = 10;
let b = 5;

console.log(a + b); // Arithmetic
console.log(a ** b); // Exponentiation

let age = 20;
if (age > 18) {
    console.log("Can Vote");
} else {
    console.log("Cannot Vote");
}

let status = (age > 18) ? 'YOU CAN VOTE' : 'YOU CANNOT VOTE';

console.log(false || 'VIRAT'); // Short-circuiting
console.log(2 & 5); // Bitwise AND

switch(num) {
    case 1: console.log('A'); break;
    case 2: console.log('B'); break;
    default: console.log('F');
}
```
