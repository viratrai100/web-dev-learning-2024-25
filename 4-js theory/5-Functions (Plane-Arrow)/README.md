# 🧠 JavaScript Theory - Functions (Normal & Arrow)

This theory project explores **JavaScript functions**, covering both **traditional** and **arrow function** syntaxes. It includes use cases, parameters, return values, and practical examples such as mathematical operations and string handling.

## 📂 About This Code

This project walks through key concepts of functions in JavaScript:

---

### 🧩 Key Concepts Covered

#### ✅ Function Basics
- Function declaration and calling
- Functions inside loops
- Parameterized functions
- Return-based functions

#### 📐 Mathematical Examples
- Average of numbers
- Sum of three numbers
- Multiplication
- Squaring a number (two methods)

#### 🔁 Functional Expressions
- Assigning function to a variable (anonymous function)
- Calling and reusing function values

#### 🏹 Arrow Functions
- Arrow syntax for concise function declarations
- Same mathematical operations with arrow functions
- Power/exponent operation using arrow functions

---

## 🔤 Sample Snippets

```javascript
// Function Declaration
function sayMyName() {
  console.log("Virat Rai");
}

// Function with Parameters
function getAverage(num1, num2) {
  let avg = (num1 + num2) / 2;
  return avg;
}

// Function Expression
let getMultiplication = function (a, b) {
  return a * b;
};

// Arrow Function
let getExp = (x, y) => {
  return x ** y;
};
```
