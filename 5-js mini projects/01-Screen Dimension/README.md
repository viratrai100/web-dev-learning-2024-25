# 📏 Real-Time Screen Dimensions

This JavaScript project dynamically displays the current width and height of the browser window. The values update live whenever the screen is resized.

## 🔗 Live Demo

- **Vercel**: [Live Link](https://js-screen-dimension-by-viratrai.vercel.app/)
- **Netlify**: [Live Link](https://js-screen-dimension-by-viratrai.netlify.app/)

## ⚙️ Technologies Used

- HTML
- CSS
- JavaScript (DOM Manipulation, `window.innerWidth`, `window.innerHeight`, Event Listeners)

## 📚 What I Learned

- How to access and use `window.innerWidth` and `window.innerHeight`
- Using `addEventListener` to detect browser resize events
- Updating DOM elements dynamically using JavaScript
- Creating real-time, responsive UI behavior

## 🔍 Project Description

This project shows the screen's current width and height in real time. When the browser window is resized, the displayed values update instantly, giving the user a live view of screen dimensions.
