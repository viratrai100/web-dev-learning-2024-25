# 🕰️ Analog Clock with JavaScript

This project is a real-time analog clock built using HTML, CSS, and JavaScript. The clock features animated hour, minute, and second hands that rotate smoothly to represent the current time.

## 🔗 Live Demo

- **Vercel**:  [Live Link](https://js-analog-clock-by-viratrai.vercel.app/)
- **Netlify**: [Live Link](https://js-analog-clock-by-viratrai.netlify.app/)

## ⚙️ Technologies Used

- HTML (for structure and clock numbers)
- CSS (for styling and custom clock hands using `--variables`, rotations, shadows)
- JavaScript (for real-time clock updates with `setInterval()` and `Date` object)

## 📚 What I Learned

- Using `setInterval()` to update UI in real-time
- Accessing current time using JavaScript's `Date` object
- Calculating rotation degrees for hour, minute, and second hands
- Applying dynamic CSS transformations (`rotate()`) with JavaScript
- Creating a circular layout using CSS variables and transformations
