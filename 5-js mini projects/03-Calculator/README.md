# 🧮 JavaScript Calculator App

This is a responsive and interactive calculator built using HTML, CSS, and JavaScript. It supports basic arithmetic operations like addition, subtraction, multiplication, and division, along with AC (All Clear), DEL (Delete), decimal inputs, and percentage functionality.

## 🔗 Live Demo

- **Vercel**:  [Live Link](https://js-calculator-project-by-viratrai.vercel.app/)
- **Netlify**: [Live Link](https://js-calculator-project-by-viratrai.netlify.app/)

## ⚙️ Technologies Used

- **HTML**: for structuring the calculator layout
- **CSS**: for styling, gradients, shadows, and button design
- **JavaScript**: for implementing all calculator logic, input handling, and operations using `eval()`

## 📚 What I Learned

- DOM manipulation with `querySelectorAll` and event listeners
- Using `eval()` to evaluate string expressions (with caution)
- Implementing custom functions for `AC`, `DEL`, and decimal handling
- Styling calculator UI with flexbox and gradients for a modern look

## 🔍 Project Description

This calculator app lets users perform real-time arithmetic operations with a clean UI. It includes essential controls like **AC**, **DEL**, and **=**, making it a functional clone of a basic handheld calculator using only frontend web technologies.
