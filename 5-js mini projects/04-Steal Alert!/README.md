# 🚫 Copy Prevention (🖕) Prank App

This fun mini JavaScript project disables the default copy action on a webpage. Instead of copying the actual content, it replaces the clipboard data with a custom emoji (`🖕`) — making it a simple and cheeky prank app.

## 🔗 Live Demo

- **Vercel**:  [Live Link](https://js-steal-alert-project-by-viratrai.vercel.app/)
- **Netlify**: [Live Link](https://js-steal-alert-project-by-viratrai.netlify.app/)

## ⚙️ Technologies Used

- **HTML**: for basic content structure
- **JavaScript**: for handling the `copy` event and overriding clipboard data

## 📚 What I Learned

- How to listen to and prevent default browser events using `addEventListener`
- Using `event.clipboardData.setData()` to programmatically set copied content
- Using `event.preventDefault()` to override native behavior

## 🔍 Project Description

This project adds a humorous touch to webpages by intercepting the user's copy command and replacing the clipboard data with a predefined message or emoji. It's a creative use of JavaScript events to understand browser behavior and DOM event handling.
