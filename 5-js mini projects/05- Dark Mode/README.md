# 🌙 Dark Mode Toggle

This project adds a **dark mode toggle button** to a webpage using JavaScript. By clicking the button, the page background and text color dynamically switch between light and dark modes.

## 🔗 Live Demo

- **Vercel**:  [Live Link](https://js-darkmode-toggle-by-viratrai.vercel.app/)
- **Netlify**: [Live Link](https://js-darkmode-toggle-by-viratrai.netlify.app/)

## ⚙️ Technologies Used

- **HTML**: for basic structure
- **CSS**: for styling dark mode and button
- **JavaScript**: for toggling the dark mode class on click

## 📚 What I Learned

- How to toggle classes dynamically using `classList.toggle()`
- Handling click events using `addEventListener`
- Implementing dark mode using CSS class switching

## 🔍 Project Description

This is a beginner-friendly dark mode toggle project using pure JavaScript and CSS. A button toggles the `dark-mode` class on the `body`, allowing for a smooth switch between light and dark themes without reloading the page.
