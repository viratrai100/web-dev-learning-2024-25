# 🚫 Disqualification Detection Page

This project disqualifies the user by displaying a warning message if:
1. The user switches to another browser tab (`visibilitychange`)
2. The screen size is changed even by 1 pixel (`resize` event)

- **Vercel**:  [Live Link](https://js-detection-page-by-viratrai.vercel.app/)

## ⚙️ Technologies Used

- **HTML**: To structure the page and message
- **CSS**: For minimal base styling
- **JavaScript**: To handle tab switching and window resizing detection
