# 🎬 Sensitive Content Video Reel

This project displays a video with a **"Sensitive Content"** warning overlay. The video is hidden behind a warning until the user clicks **"See Video"**, after which the reel starts playing.

- **Enhanced Version (Improved UI + UX)**:
  - Netlify: [Live Link](https://js-videoplaywarning-enhanced-by-virat.netlify.app/)

## ⚙️ Technologies Used

- **HTML**: For video structure and warning elements
- **CSS**: For styling the overlay and video container
- **JavaScript**: To control the hiding of the overlay and auto-playing the video

## 📚 What I Learned

- How to create custom warning overlays for media content
- Managing HTML5 video with JavaScript (`play()`)
- Centering elements with `transform: translate(-50%, -50%)`
- Improving UX by gating video content behind confirmation
