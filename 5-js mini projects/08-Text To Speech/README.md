# 🗣️ Text-to-Speech Web App

This project allows users to type any text into an input box and click a **"Speak"** button to hear the text read aloud using the **Web Speech API**. It's a simple but powerful demonstration of how browser-based speech synthesis works.

## 🔗 Live Demo

- **Vercel**:  [Live Link](https://js-text-to-speech-by-viratrai.vercel.app/)
- **Netlify**: [Live Link](https://js-text-to-speech-by-viratrai.netlify.app/)

## ⚙️ Technologies Used

- **HTML**: For structure and input elements
- **CSS**: For basic styling and layout
- **JavaScript**: To access and use the `SpeechSynthesisUtterance` API

## 📚 What I Learned

- Using the `SpeechSynthesisUtterance` interface
- Leveraging the `speechSynthesis.speak()` method for browser-based voice output
- Handling input values in JavaScript for dynamic interaction
- Implementing a simple UI for speech functionality
