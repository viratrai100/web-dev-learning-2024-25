# 🎥 Video Fullscreen Toggle with Keyboard

This project enables users to toggle a video player between normal and fullscreen widths by pressing the **`F` key** on the keyboard. It's a simple JavaScript-based enhancement for video interactivity and user control.

## 🔗 Live Demo

- **Vercel**:  [Live Link](https://js-fullscreen-toggle-by-viratrai.vercel.app/)
- **Netlify**: [Live Link](https://js-fullscreen-toggle-by-viratrai.netlify.app/)

## ⚙️ Technologies Used

- **HTML**: To embed the video element
- **JavaScript**: To listen for keyboard events and dynamically toggle video size

## 📚 What I Learned

- Handling `keydown` events in JavaScript
- Using conditions to toggle states with a boolean (`isFullScreen`)
- Manipulating video element styles using JavaScript
- Enhancing UX with simple keyboard shortcuts
