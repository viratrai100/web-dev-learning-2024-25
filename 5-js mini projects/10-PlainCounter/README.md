# 👆 Simple Click Counter Project

This is a beginner-friendly JavaScript project that tracks the number of times a button is clicked and dynamically displays the updated count on the page. It features smooth styling, hover effects, and a responsive design.

## 🔗 Live Demo

- **Vercel**:  [Live Link](https://js-plain-counter-by-viratrai.vercel.app/)
- **Netlify**: [Live Link](https://js-plain-counter-by-viratrai.netlify.app/)

## ⚙️ Technologies Used

- **HTML**: Structure of the layout and elements  
- **CSS**: Styling, layout, hover effects, and transitions  
- **JavaScript**: Counter logic and dynamic DOM manipulation

## 📚 What I Learned

- How to manipulate the DOM using JavaScript  
- Event handling using `addEventListener`  
- Keeping state with JavaScript variables (`let count`)  
- Styling interactive elements with hover transitions  
- Designing a visually clean and engaging UI
