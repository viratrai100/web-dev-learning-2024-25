# ⏰ Neon Clock Project (Analog + Digital)

This is a stylish and fully functional **JavaScript-based clock project** that features both analog and digital time display. It comes with glowing animations, custom clock hands using CSS variables, and dynamic time updates via JavaScript.

## 🔗 Live Demo

- **Vercel**:  [Live Link](https://js-analog-digital-clock-by-viratrai.vercel.app/)
- **Netlify**: [Live Link](https://js-analog-digital-clock-by-viratrai.netlify.app/)

## ⚙️ Technologies Used

- **HTML**: Semantic structure of the clock face and digital time
- **CSS**: Custom properties, pseudo-elements, glowing effects, and keyframe animations
- **JavaScript**: Time logic, DOM updates every second, 12-hour format conversion

## 📚 What I Learned

- How to create analog clock hands using `transform: rotateZ(deg)`
- Using CSS custom properties (`--clr`, `--i`) to dynamically style elements
- JavaScript `Date` object to fetch real-time hours, minutes, seconds
- Creating a flickering colon effect using keyframes
- Combining both **visual design** and **functional logic** in one project
