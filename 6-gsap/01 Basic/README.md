# 🚀 GSAP Project 1 — Animated Header with Timeline

This project demonstrates the use of **GSAP (GreenSock Animation Platform)** to create a visually engaging header animation using the GSAP timeline method. The project features a minimal navigation bar and a central heading, both animated with smooth transitions on page load.

## 🌐 Live Demo

- 🔗 [View on Vercel](https://gsap-project1-by-viratrai.vercel.app/)
- 🔗 [View on Netlify](https://gsap-project1-by-viratrai.netlify.app/)

## 💡 Features

- Responsive layout with a dark theme
- GSAP timeline animations for staggered header appearance
- Clean and modular HTML, CSS, and JavaScript structure
- Dynamic scaling and fade-in effects for text elements

## 📁 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- GSAP (CDN)

## 📚 What I Learned

- How to implement `gsap.timeline()` to chain multiple animations
- The use of `from()` method in GSAP to animate elements from a starting state
- How to apply `stagger`, `opacity`, `y`, and `scale` transformations to elements for dynamic entry animations
- Improved understanding of layout structuring using Flexbox
