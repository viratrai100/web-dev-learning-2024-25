# 🎯 GSAP Project 3 — Interactive SVG String Animation

This project features a dynamic **SVG path morphing animation** that responds to mouse movement. As you move your cursor across the screen, the string bends like it's being pulled — simulating a responsive wire or rope effect. The animation is powered by **GSAP**.

## 🌐 Live Demo

- 🔗 [View on Vercel](https://gsap-svg-string-animation-by-viratr.vercel.app/)
- 🔗 [View on Netlify](https://gsap-svg-string-animation-by-viratrai.netlify.app/)

## 💡 Features

- Custom **SVG Path** shaped like a curved horizontal string
- Real-time animation on `mousemove`:
  - The SVG path dynamically updates its `Q` (quadratic curve) control point to follow the mouse
- Smooth morphing with `gsap.to()` and easing
- Elastic return effect when the mouse leaves the area

## 🛠️ Technologies Used

- **HTML5** – Markup for SVG and structure
- **CSS3** – Background styling and layout
- **JavaScript (ES6)** – DOM event handling
- **GSAP 3.12.7**
  - `gsap.to()` for smooth SVG morphing
  - `attr:{ d: ... }` to animate SVG path dynamically

## 📚 What I Learned

- How to use `mousemove` events to capture real-time cursor positions
- How to update and animate SVG path `d` attributes using GSAP
- The use of `elastic.out` easing for a bouncy reset effect
- Real-time path morphing based on dynamic user input

## 📸 Visual Preview

> 🖱️ Move your mouse over the SVG string — watch it bend with the cursor like a pulled wire. On leaving, it bounces back into place smoothly.
