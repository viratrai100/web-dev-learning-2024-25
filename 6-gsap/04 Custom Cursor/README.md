# 🖱️ GSAP Project 4 — Interactive Custom Cursor with Image Hover Effect

This project showcases a **custom circular cursor** that smoothly follows the user's mouse movement using GSAP, and **transforms on image hover**. The image section responds to mouse events by enlarging the cursor and displaying a contextual message (`View More`), creating a modern, interactive UI feel.

## 🌐 Live Demo

- 🔗 [View on Vercel](https://gsap-custom-cursor-by-viratrai.vercel.app/)
- 🔗 [View on Netlify](https://gsap-custom-cursor-by-viratrai.netlify.app/)

## 💡 Features

- Smooth **GSAP-powered cursor tracking**
- Enlarging cursor animation on image hover
- Responsive text inside cursor (`View More`) on hover
- Cursor smoothly shrinks and resets on mouse leave
- Works consistently across screen sizes using `position: fixed`

## 🛠️ Technologies Used

- **HTML5** – Page structure and image container
- **CSS3** – Layout, cursor styles, and positioning
- **JavaScript (ES6)** – DOM manipulation and event handling
- **GSAP 3.12.7**
  - `gsap.to()` for smooth cursor translation and scaling

## 📚 What I Learned

- How to build a **custom cursor** with `position: fixed` for better responsiveness
- Using `mousemove` to track coordinates and animate cursor position
- Enhancing UX by updating content dynamically inside the cursor on hover
- GSAP usage for both **positional animation** and **scale transformation**
- Managing z-index and event layering for interactive overlays

## 📸 Visual Preview

> 🖱️ Move your cursor around the screen — a small white circle follows. Hover over the image and watch it grow with a “View More” message, then shrink back when you leave.
