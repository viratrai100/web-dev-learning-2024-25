# 📱 GSAP Project 5 — Animated Slide-In Navigation Menu

This project demonstrates a **responsive off-canvas navigation menu** with smooth GSAP animations. On clicking the hamburger menu icon, a blurred glassmorphic side menu slides in with staggered menu item animations. Clicking the close (X) icon smoothly reverses the animation.

## 🌐 Live Demo

- 🔗 [View on Vercel](https://gsap-sidebar-navbar-by-viratrai.vercel.app/)
- 🔗 [View on Netlify](https://gsap-sidebar-navbar-by-viratrai.netlify.app/)

## 💡 Features

- Responsive **hamburger to menu overlay** animation
- Modern **glassmorphism** style menu panel
- Staggered animation for nav links
- Toggle functionality using GSAP `.play()` and `.reverse()`
- Uses `GSAP Timeline` for organized animation flow
- Remix Icon support for clean icons

## 🛠️ Technologies Used

- **HTML5** – Semantic structure for nav and menu sections
- **CSS3** – Styling with backdrop-filter for blur effect
- **JavaScript (ES6)** – Interactivity and animation triggering
- **GSAP 3.12.7**
  - Timeline-based animation
  - `to()` and `from()` transitions with stagger effects

## 📚 What I Learned

- Creating a **toggleable side menu** using GSAP timeline controls
- Using `.paused()` to conditionally control animations
- Applying **glassmorphism** using `backdrop-filter` and semi-transparent backgrounds
- Working with `stagger`, `from`, and `to` in timeline sequencing
- Efficient menu interactions using `click` events and reverse animations

## 📸 Visual Preview

> 🧭 Click the hamburger icon to open the glassy side panel with animated links, and tap the close button to slide it back. Seamless, elegant, and interactive.
