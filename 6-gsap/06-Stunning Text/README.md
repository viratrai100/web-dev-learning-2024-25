# 📱 GSAP Project 6 — 🎯 Split Text Animation using GSAP

This project demonstrates a clean and elegant **split text animation** using GSAP. The text is dynamically broken into individual spans, then animated with a staggered entrance effect to create a smooth, engaging UI animation.

## 🚀 Live Demo

- **Vercel:**  [Live Demo](https://gsap-split-text-animation-by-viratr.vercel.app/)
- **Netlify:** [Live Demo](https://gsap-split-text-animation-by-viratrai.netlify.app/)

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (DOM Manipulation)**
- **GSAP (GreenSock Animation Platform)**

## 📚 What I Learned

- How to manipulate text content using JavaScript by splitting it into individual characters.
- Dynamic DOM manipulation: injecting `<span>` elements for styling and animation.
- Using **GSAP's `from()` method** for staggered animations.
- Conditional span classing to animate first and second halves differently.
- Improved understanding of **stagger timing**, **opacity**, and **transform effects** with GSAP.
