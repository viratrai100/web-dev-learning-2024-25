# ✨ GSAP Project 6 — Digital Performance Layout with Hero Animations

A visually appealing web layout inspired by digital branding aesthetics. This project demonstrates **entrance animations with GSAP**, a stylish fixed navigation bar, interactive hover effects on images, and a creatively underlined headline — all in one immersive layout.

## 🌐 Live Demo

- 🔗 [View on Vercel](https://gsap-landingpage-by-viratrai.vercel.app/)
- 🔗 [View on Netlify](https://gsap-landingpage-by-viratrai.netlify.app/)

## 💡 Features

- Animated **GSAP entry transitions** for all hero elements (images + text)
- Clean, modern **fixed navigation bar** with hover-animated contact button
- Decorative **SVG underline effect** under hero headline
- Responsive, fluid layout structure
- Subtle **hover image animations** for interactivity

## 🛠️ Technologies Used

- **HTML5** – Semantically structured layout and hero section
- **CSS3**
  - `position: fixed`, `absolute`, and `flexbox` layout handling
  - Button hover animation using `left` transition
  - Decorative underline with background-image
- **JavaScript (ES6)**
  - DOM animations triggered on load
- **GSAP 3.12.7**
  - Smooth `from()` animations on multiple elements
  - Delay, opacity, and directional control for enhanced visual experience

## 📚 What I Learned

- Building a **visually aesthetic layout** using image positioning and modern typography
- Integrating **GSAP’s `from()` method** for precise, staged animations
- Creating **SVG underline** decorations using `::after` and `background-image`
- Hover interaction logic using smooth `margin-top` transitions
- Using GSAP with non-timeline animations for straightforward entry effects

## 🎯 Key UI Elements

- 📌 Fixed Navbar with structured links and animated CTA
- 🖼️ Three individually animated hero images
- 🟢 Sliding green hover effect behind "Contact Us"
- 🖊️ SVG underline using `::after` pseudo-element
