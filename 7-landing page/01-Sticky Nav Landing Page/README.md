# 🌐 Sticky Nav Landing Page

This is a smooth-scroll based landing page project featuring a sticky navigation bar, section-based layout, and minimal CSS design. The navigation bar remains fixed at the top of the screen while scrolling, improving user experience and accessibility.

## 🚀 Live Demo

- **Vercel**:  [View on Vercel](https://nav-sticky-landing-page-by-viratrai.vercel.app/)
- **Netlify**: [View on Netlify](https://nav-sticky-landing-page-by-viratrai.netlify.app/)

## 🎯 Features

- Sticky navbar stays fixed on top of the screen
- Sectioned layout: HOME, ABOUT, SERVICES, CONTACT, OTHER
- Smooth scrolling navigation
- Scrollbar custom styling
- Responsive and clean UI using pure HTML and CSS

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 What I Learned

- How to implement sticky/fixed navigation bars
- Using `scroll-behavior: smooth` for native smooth scrolling
- Styling custom scrollbars using `::-webkit-scrollbar`
- Positioning with `position: fixed` and managing z-index
- Section linking using `id` and anchor tags
