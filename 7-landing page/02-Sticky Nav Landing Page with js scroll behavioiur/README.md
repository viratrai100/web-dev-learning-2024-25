# 🌐 Sticky Nav Landing Page with JavaScript Scroll Behavior

This landing page demonstrates a sticky navigation bar that dynamically attaches to the top of the screen using JavaScript when the user scrolls past the hero section. It uses smooth scrolling, modern styling, and interactive UI elements.

## 🚀 Live Demo

- **Vercel**:  [View on Vercel](https://scroll-behaviour-nav-by-viratrai.vercel.app/)
- **Netlify**: [View on Netlify](https://scroll-behaviour-nav-by-viratrai.netlify.app/)

## 🎯 Features

- Sticky navbar with JavaScript scroll detection
- Sectioned layout with five parts: HOME, ABOUT, SERVICES, CONTACT, OTHER
- Smooth transition effects on scroll
- Scrollbar styling with `::-webkit-scrollbar`
- Navigation underline animation using `nav-all-space` bar
- Responsive design using pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla)

## 📚 What I Learned

- How to use JavaScript to detect scroll position using `getBoundingClientRect()`
- Toggling classes dynamically with JavaScript to make elements sticky
- Implementing smooth scroll UX with native `scroll-behavior`
- Styling and animating underlines and scrollbars
- Improved semantic structure and code organization
