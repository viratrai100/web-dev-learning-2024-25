# 🎨 Simple But Not Easy - CSS Visual Showcase

This creative layout is a visually rich CSS project titled **"Looks Simple But Not Easy"**, inspired by modern portfolio and magazine-style designs. It uses bold typography, layered image compositions, and absolute positioning to create a compelling visual experience without JavaScript.

## 🚀 Live Demo

- **Vercel**:  [View on Vercel](https://css-visual-sowcase-by-viratrai.vercel.app/)
- **Netlify**: [View on Netlify](https://css-visual-sowcase-by-viratrai.netlify.app/)

## 🎯 Features

- Split three-part horizontal layout using pure CSS
- Overlay effects for background image blending
- Bold typography with rotated vertical text
- Custom font usage for aesthetic appeal (`monument`, `gilroy`)
- Responsive positioning using `transform`, `absolute`, and `flex`
- Hidden overflow to maintain clean viewport presentation

## 🛠️ Technologies Used

- HTML5
- CSS3 (Positioning, Flexbox, Overlays)

## 📚 What I Learned

- How to design a modern web layout using only HTML and CSS
- Mastered use of `position: absolute` and `transform` for layered design
- Creating vertical text using `rotate()` and `transform-origin`
- Handling image overlays with transparency for stylized visuals
- Use of web-safe fonts and fallback strategies
